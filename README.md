# 📊 Business Insight Analytics – Power BI Dashboard

## 🚀 Overview

Business Insight Analytics is a comprehensive Power BI dashboard designed to provide a 360° analytical view of business performance across Marketing, Sales, Supply Chain, Finance, and Executive Management.

This project simulates a real-world enterprise Business Intelligence solution where data is integrated from multiple sources and transformed into actionable insights for decision-makers.

---

## 🎯 Project Objective

The objective of this project is to:

- Integrate data from multiple sources (SQL, CSV, Excel)
- Perform data cleaning and transformation
- Design a structured data model
- Create role-based dashboards for different stakeholders
- Monitor KPIs across departments
- Enable data-driven strategic decision-making

---

## 🗄️ Data Sources

The dashboard integrates data from:

- SQL Database (Transactional Data)
- CSV Files (Operational Data)
- Excel Files (Financial & Supporting Data)

Data from all sources was imported into Power BI, cleaned, transformed, and modeled into a unified data structure.
